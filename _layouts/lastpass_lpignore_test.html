LastPass data-lpignore Override Test

Minimal reproduction page for a LastPass support ticket: fields below are configured with data-lpignore="true" and other documented opt-out attributes, and should never be touched by LastPass. Any badge that turns red means LastPass injected its UI into (or filled) that field anyway.

How to record this for support

  1. Start from a fresh browser session (LastPass extension enabled, default settings) and load this page.
  2. Show the field and its attribute string underneath it (visible proof of config).
  3. Wait a few seconds without touching the field — watch for the LastPass icon to appear and/or the badge to flip.
  4. Show the Detection Log panel below picking up the event with a timestamp.
  5. Click Reset Fields between takes to re-arm the test without reloading.
